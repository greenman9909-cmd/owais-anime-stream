Product, not a wrapper

One interface for discovery and playback.

The web preview and APK share the same responsive UI. Catalogue data comes from ani.pm's public partner API and playback stays inside ani.pm's official player, so the app never needs private media URLs.

Catalogue

Public partner API

The app uses the read-only, keyless API documented by ani.pm and requests adult=0 by default.

GET /api/partner/v1/top?range=week GET /api/partner/v1/titles?q=... GET /api/partner/v1/series/{anilistId} GET /api/partner/v1/recent
Playback

Official player embed

Each episode stays inside the provider's frame. OWAIS only drives documented controls and reads documented progress events.

https://ani.pm/embed/ani/{anilistId}/{episode}/{sub|dub} postMessage namespace: anipm.player · v1
