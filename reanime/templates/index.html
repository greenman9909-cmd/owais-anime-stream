Arquitectura de Ingeniería

Resolución de transmisiones tolerante a fallos y proxy de borde diseñado para máxima fiabilidad.

Conmutación por Error en Clúster de 3 Servidores

La conmutación automática en cascada entre los nodos perimetrales Sora, Neko y Zozo garantiza una entrega continua incluso ante caídas de proveedores regionales.

Subtítulos con Precisión de Cuadro

Subtítulos sincronizados WebVTT y ASS con calibración de compensación personalizada (±10s) renderizados en pistas de video HTML5 nativas.

Sincronización de Catálogo Dual

Compatibilidad nativa para identificadores AniList y MyAnimeList con traducción automática de metadatos y mapeo de slugs.

Escudo de Tokens HMAC-SHA256

Los orígenes del CDN y las URL de reproducción están firmadas con tokens criptográficos con expiración para evitar enlaces directos no autorizados.

Salto de Intro y Outro AniSkip

Integración directa con la API de AniSkip que proporciona marcadores de tiempo para omitir intros y créditos automáticamente.

Bus de Eventos API PostMessage

Protocolo de eventos bidireccional que emite eventos ready, play, pause, timeupdate y ended para una integración perfecta con aplicaciones web anfitrionas.

<!-- Opciones de Ruta:
  /embed/ani/:id/:episodio   - Por ID numérico de AniList (ej. 21 = One Piece)
  /embed/mal/:id/:episodio   - Por ID de MyAnimeList
  /embed/:slug/:episodio     - Por slug o consulta de título (ej. one-piece-21)
  
Parámetros URL:
  ?track=sub | dub          - Pista de audio por defecto (defecto: sub)
  ?player=hls | direct      - Motor HLS adaptativo o enlace directo
-->
import React, { useEffect, useRef } from "react";

interface AnimePlayerProps {
  id: number | string; // AniList ID (ej. 21) o slug
  episode?: number;
  track?: "sub" | "dub";
  onReady?: (server: string) => void;
  onEnded?: () => void;
  onTimeUpdate?: (currentTime: number, duration: number) => void;
}

export const AnimePlayer: React.FC<AnimePlayerProps> = ({
  id,
  episode = 1,
  track = "sub",
  onReady,
  onEnded,
  onTimeUpdate,
}) => {
  const iframeRef = useRef<HTMLIFrameElement>(null);

  useEffect(() => {
    const handleMessage = (e: MessageEvent) => {
      if (e.data?.source !== "AnimeXOsource_Owais" || e.data?.type !== "yoru:event") return;
      const { event, server, currentTime, duration } = e.data;

      if (event === "ready") onReady?.(server);
      if (event === "timeupdate") onTimeUpdate?.(currentTime, duration);
      if (event === "ended") onEnded?.();
    };

    window.addEventListener("message", handleMessage);
    return () => window.removeEventListener("message", handleMessage);
  }, [onReady, onEnded, onTimeUpdate]);

  return (
    <div style={{ position: "relative", width: "100%", aspectRatio: "16/9", background: "#000" }}>
      <iframe
        ref={iframeRef}
        src={`http://127.0.0.1:8000/embed/ani/${id}/${episode}?track=${track}`}
        style={{ width: "100%", height: "100%", border: "none" }}
        allow="autoplay; fullscreen; picture-in-picture"
        allowFullScreen
        referrerPolicy="no-referrer-when-downgrade"
      />
    </div>
  );
};

// Escuchar eventos del reproductor en la aplicación host
window.addEventListener("message", (event) => {
  // Validar origen
  if (event.data?.source !== "AnimeXOsource_Owais" || event.data?.type !== "yoru:event") return;

  const eventName = event.data.event;
  const payload = event.data;

  switch (eventName) {
    case "ready":
      console.log(`Reproductor listo en el nodo de clúster: ${payload.server}`);
      break;

    case "play":
      console.log("El usuario reanudó la reproducción");
      break;

    case "pause":
      console.log("El usuario pausó la reproducción");
      break;

    case "timeupdate":
      // Guardar progreso en su base de datos o localStorage
      const progressPercent = (payload.currentTime / payload.duration) * 100;
      console.log(`Progreso: ${progressPercent.toFixed(1)}% (${payload.currentTime}s)`);
      break;

    case "skip":
      console.log(`Omitido ${payload.type} hasta el segundo: ${payload.to}s`);
      break;

    case "serverchange":
      console.log(`El usuario cambió al servidor: ${payload.server}`);
      break;

    case "failover":
      console.warn(`Nodo ${payload.from} degradado. Conmutado automáticamente a: ${payload.to}`);
      break;

    case "ended":
      console.log("¡Episodio terminado! Reproducir siguiente...");
      // Ejemplo: avanzar episodio en estado:
      // setEpisode(prev => prev + 1);
      break;

    case "error":
      console.error(`Error de reproducción en ${payload.server}: ${payload.message}`);
      break;
  }
});
